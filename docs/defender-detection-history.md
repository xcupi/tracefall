# Defender DetectionHistory: bounded modern subset

`defenderhistory@1` recognizes evidence-relative DetectionHistory directory components plus checked LTV headers, independent of basenames and host/IOC strings. Content confirmation recognizes the Magic.Version family; import accepts exactly Magic.Version:1.2. Legacy, optional flag_1=4, unknown unframed nested types, corrupt lengths/types/UTF16/padding/tails fail atomically, not as empty success.

Limits: 1 MiB source, 4096 top-level entries, 128 total ordered resource sections, 4096 nested values per resource, one record per source. Nesting is exactly one framed resource-value layer, not arbitrary recursive parsing. Values and duplicate keys/resources are lossless arrays. Unknown type0 flags and numeric signed ambiguity remain raw bits. Type7 is explicitly length-prefixed ASCII, not fixed five bytes. Nested size includes its repeated size word; empty zero-byte blobs and version1/20-byte empty headers are distinct valid blob forms. Neither makes an empty source valid.

A source emits one antimalware_history_observation. GUID identity comes from the checked header bytes, not filename. Only initial_detection_time FILETIME supplies Timestamp (zero remains undated); there is no first-nonzero, mtime, or filename fallback. All original FILETIME uint64 and zero presence are retained. Conversion uses integer seconds and remaining 100ns ticks, never floats. Other top-level roles are reverse-engineered last_threat_status_change and remediation_time, not success evidence. Nested uint64s remain literal typed values; documented tracking keys may be interpreted as FILETIME in private examination, never arbitrary uint64s.

Private RawEvidence JSON stores full source bytes (base64), ordered typed entries and resource/nested arrays with absolute offsets, padding and numeric bits. These include sensitive arbitrary strings: inspect only in access-controlled evidence detail. Default normalized events expose GUID, threat numeric ID, resource count, hashes, EOF and top-level FILETIMEs only; threat labels, resource/command/domain/unknown strings are withheld. Default event list/report must not include RawEvidence. Explicit raw-evidence APIs still disclose raw bytes to the authorized examiner; this is not universal secret redaction.

The av-threat-detected rule declares history Inputs but history alone is not a maliciousness indicator and seeds no finding. It attaches only to one unambiguous existing detection group through a validated canonical GUID within the same case, acquisition and host scope. Literal IDs are not rewritten; malformed IDs cannot join. Source counts label EVTX/support/history separately, never added as attacks or independent confirmation. History context does not supply investigation artifact-diversity credit. Numeric status/error/action values imply neither process-start, transfer success nor remediation success.
